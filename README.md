# مدينة المافيا

لعبة مافيا عربية جماعية للـPC، تتضمن غرفاً بكود، أدواراً سرية، مراحل ليل/نهار، تصويتاً، ومايكاً مباشراً عبر WebRTC.

## التشغيل

```bash
npm install
node server.js
```

افتح `http://localhost:3000`. للعب مع أجهزة أخرى على نفس الشبكة افتح عنوان IP لجهاز الاستضافة مع المنفذ `3000`.

للنشر على الإنترنت يلزم تشغيله بخادم Node.js مع HTTPS حتى يعمل المايك في كل المتصفحات.
